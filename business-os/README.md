# Brainforge business template

This standalone template contains a conversational interview and bounded
business memory. For the easiest start across clients, use the root
[Brainforge setup](../README.md) instead.

To use this template on its own, copy this folder to a new business folder,
open Claude Code there and run `/setup`.

## Contents

```text
CLAUDE.md              Operating instructions
memory/                 Business, voice and current priorities
identity/               Visual identity guide
content/                Content deliverables
ads/                    Campaign and reporting deliverables
operations/             Operational deliverables
.claude/skills/setup/    Initial interview
```

This standalone folder includes setup only. The root Brainforge workflow now
includes [marketing, release and feedback procedures](../onboarding/SPECIALISTS.md)
and general capability expansion. Use the full repository's `start` entry to
access them; copying only this folder does not bundle those procedures.
Its memory budgets are instructions, not an automatic enforcement mechanism.
