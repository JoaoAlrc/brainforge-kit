## Brainforge modifications

Brainforge contributors condensed and rewrote the selected guidance for
provider-neutral task routing, existing product memory, one-question discovery,
on-demand references, evidence-based review and bounded correction. Product
decisions and visual direction remain central; review claims depend on tools
actually executed. Host permissions, role boundaries and delivery schemas take
precedence over the adapted procedure.

This directory does not distribute upstream launchers, binaries, hooks, native
agent configurations, browser overlays, images, fonts or font catalogs. Engine
commands, randomized concept selection, interactive decision servers, automatic
detection, native agent installation and live element editing are not implemented
by this adaptation. Browser rendering, asset generation and external services
require separately available tools and authorization.
