# Distribution boundary

Brainforge Kit 0.2.0 is an independent source distribution. The application is a
separate private consumer. Kit access does not grant application repository access.

General creation, marketing, design and sector reasoning remain included. The
original property guide, content-pattern collection and carousel HTML asset were
reserved outside this distribution for optional pack development; they are not
finished commercial products. Customer material and internal course plans are
never distributed. A content pack provides assets; a plugin adds an integration
or callable tools and needs its own permissions. Neither is required for core use.

Consumers pin a Git commit and bundle its files with their release. Update shared
procedures here, then advance the consumer pin after compatibility tests. Do not
copy-edit agent files in the consumer or fetch a mutable branch during a run.
Preserve LICENSE and THIRD_PARTY_NOTICES.md with distributed content.
