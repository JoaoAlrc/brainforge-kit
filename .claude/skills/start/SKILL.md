# Start Brainforge

Read [the shared workflow](../../../onboarding/SETUP.md) and follow it.
Detect the current client from the session, not the installed folder names.
Use the user's language and ask only unanswered questions needed for the goal.
Resume existing work instead of restarting setup. No runtime installation or
manual configuration is required from the user.
